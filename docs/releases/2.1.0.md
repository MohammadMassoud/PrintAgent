# PrintAgent SDK 2.1.0 — stable

Print ZPL labels, ESC/POS receipts and other printer-ready RAW commands from Blazor Server and .NET 10 to compatible Windows queues and TCP destinations.

## Downloads and compatibility

| Component | Version |
| --- | --- |
| NuGet integration SDK | **2.1.0** |
| Compatible Windows x64 agent | **2.0.0** |
| Local protocol | **2** |

This is an SDK-only release. The attached `SinergiaPrint-Setup.exe` is the existing published Windows agent **2.0.0**; it has not been rebuilt for this release.

```shell
dotnet add package SinergiaAI.PrintAgent --version 2.1.0
```

The attached `.nupkg` is the package downloaded from [NuGet.org](https://www.nuget.org/packages/SinergiaAI.PrintAgent/2.1.0), including its NuGet repository signature. See `SHA256SUMS.txt` for the hashes of both assets. The Windows installer is currently unsigned and may trigger a SmartScreen warning. [Download verification](https://github.com/MohammadMassoud/PrintAgent/blob/main/docs/downloads.md).

## What's new

- A single `SendAsync` method name accepts strings, byte arrays, text lists, byte-array lists and prepared `PrintDocument` lists.
- Caller-supplied request keys are optional. Each plain call without a key creates a new request, even when content is identical.
- Prepared documents retain their generated or explicit identities across calls; persist the document identities, destinations and bytes before submission when recovery is required.
- `SendByteAsync`, `SendBatchAsync` and 2.0 signatures remain compatible forwarding aliases, hidden from IntelliSense.
- Strict text encoding, unchanged binary payloads, local durable queues and protection against automatic replay remain in place.

```csharp
await PrintAgent.SendAsync(printerId, commands);       // string
await PrintAgent.SendAsync(printerId, rawBytes);       // byte[]
await PrintAgent.SendAsync(printerId, commandList);    // list of strings

// Persist the prepared documents before submission when recovery is needed.
var documents = new[]
{
    PrintAgent.CreateTextDocument(printerId, commands),
    new PrintDocument(printerId, rawBytes, savedBinaryKey)
};
await PrintAgent.SendAsync(documents);
```

Never automatically repeat a keyless call after a timeout or lost response: the earlier job may already have reached the printer. `Sent` confirms delivery to the Windows queue or TCP endpoint, not physical paper output.

## Requirements and guides

Use Windows x64 for the agent and .NET 10 with Blazor Server / Interactive Server for the SDK. Applications provide commands supported by the target printer. PrintAgent does not render HTML, PDF, Office documents or images, detect printer languages, or provide a standalone WebAssembly SDK.
