# SinergiaPrint.Client

Typed HTTP client for a separately hosted SinergiaPrint API. Targets .NET 10; initial preview.

Register in your **server/backend**, keeping the API key in protected server configuration:

```csharp
using SinergiaPrint.Client;

builder.Services.AddSinergiaPrint(
    new Uri(builder.Configuration["Printing:Url"]!),
    builder.Configuration["Printing:ApiKey"]!);
```

Inject `PrintingClient`, select the installation/printer explicitly, and submit the bytes generated by your application:

```csharp
var printers = await printing.ListPrintersAsync(installationId);
var job = await printing.PrintAsync(
    installationId, selectedPrinterId, bytes, requestKey);
var result = await printing.GetJobAsync(job.Id);
```

Keep `requestKey` unchanged when retrying the same submission after a communication error. The initial response means the job was queued. Poll its ID to obtain the eventual result.

Do not embed the API key in Blazor WebAssembly or browser code. Use your authenticated backend as the intermediary. If the API should run inside your application instead, use **SinergiaPrint.Server**.

The Windows agent is installed separately. It forwards raw bytes to the selected printer without language validation. `Sent` confirms data delivery to the spooler/TCP stream, not physical paper output; inspect the printer before resubmitting a failed or uncertain job.
